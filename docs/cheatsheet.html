Every stub in .claude/commands/ just points at .ai/prompts/ — the prompts are the source, tool-agnostic. flows.fix: recall → understand → implement → test → record → retro?. flows.tiny: implement → verify — for a provably local change only; unsure whether it qualifies means it doesn't.

One-way doors — stop, state, continue elsewhere

  1. Dependency — add, remove, bump. Includes package-lock.json.
  2. Migration — schema or data.
  3. External contract — anything outside the repo calls it.
  4. Test deleted or weakened.
  5. Auth, secrets, payments.
  6. Outside the repo — shared branch, rewritten history.
  7. Gate's own scope — one owner, .claude/hooks/budget.mjs's GATE_SCOPE, which emits the live list to .ai/harness/gate-scope.json on every run. Enforced live — hook blocks it.

Override: HARNESS_DOOR_OPEN=1, and say so in the digest.

Two-way — run, report after

  • Any edit on an unpushed branch.
  • Tests, refactors, renames.
  • Reading anything, anywhere.
  • New files inside the declared blast radius.
  • Failed experiments — git branch -D is the undo.

.ai/MODEL.md is a standing exception: human-owned, hook-blocked regardless of an active run.

Gates — bash .ai/harness/verify.sh <tier>

TierRunsWhen
fasteslintafter a unit of work
fullfast + jest --ci + hook-test.shbefore every commit
smokefull + production build + generic route-mount checkat a checkpoint mid-implement
deepsmoke + full playwright e2e suiteonce, before handing back

smoke and deep both drive the actual production build (dist/, served by e2e/serve-dist.mjs), not ng serve. Exit 0 or 1, nothing else. In this container: PW_CHROMIUM=/opt/pw-browsers/chromium bash .ai/harness/verify.sh deep.

Never trust

  • VERIFY: PASS alone — read the test diff for a spec that only asserts toBeTruthy().
  • status: completed — check git diff --stat actually changed something.
  • A metric that improved right after its own config was edited.
  • An empty list — zero checks is not "nothing failed."
  • A citation that resolves — proves the line exists, not that it's still the right one.

Where things live

  • .ai/run/<slug>/brief, journal, state.json, emits, digest, retro — hours, deleted when the work lands
  • .ai/decisions/NNNN-*.mdwhy a change happened — permanent, append-only
  • .ai/bank/lessons that outlive this repo — human-curated, never auto-written
  • .ai/MODEL.mdstructure and invariants — human-owned, hook-guarded
  • CLAUDE.mdcommands and conventions — the one owner of both
  • .ai/harness/check-citations.shresolves every file:line and bare-path citation in a doc
  • .ai/harness/handoff.shwrites HANDOFF.md with no model call, stamped if the run is still active
  • .ai/harness/emit.shwrites a skill's <skill>.json, no model call — git as truth
  • .ai/harness/ledger.shjq roll-up of every emit, by skill and by inferred flow
  • .ai/harness/gate-scope.jsonthe door-7 path list — one owner, generated, not hand-kept
  • .ai/harness/OWED.mdhuman-owed door-7 fixes and bank cards with an unbuilt mechanism
