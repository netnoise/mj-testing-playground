# House style consult

A one-hour brief for a designer consult. Part 1 asks the questions that apply to
every app (surface levels, accent, type size, shell, meaning colours, states,
dark only). Part 2 has one sheet per project with its densest screen.

Open [`index.html`](index.html) directly in a browser; the screenshots are in
`screens/`. The published copy is the
[House Style Consult](https://claude.ai/artifact/Jht6PMdcaobGraz117KPW1) artifact.

The same folder is committed to both `mj-testing-playground` (Klaxon) and
`tritrack`. Edit both copies together, or republish the artifact and copy it back.

To reuse the brief for a new project, copy the "Next project" sheet in Part 2
and fill in the four facts and three questions.
